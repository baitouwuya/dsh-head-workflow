# Native blink construction and visual handoff

Build from the connected canvas input inside the native Lab. Read the repository base and correction pins from runtime configuration, verify both revisions and their ancestry, and run the configured tests before and after the fitted adapter. Host geometry, arrays, editable scenes and renders are diagnostic evidence only. They must not substitute for the native construction or its final visual review.

Inspect the actual source geometry, coordinate frame, components, corner UVs, encoded images, materials and existing hierarchy/morphs. Derive roles and correspondence at runtime. Keep the eyeballs stationary, preserve original neutral source geometry and appearance, and deform complete original lash components. Keep all earlier failed evidence and the accepted frozen face unchanged.

Use the tested source modules for measured exterior boundary construction, source-band fitting and original lash motion. Report actual boundary continuity, contact support, strain, interval collapse, clearance and normal diagnostics. Numeric thresholds are diagnostics, not publication blockers. Do not fabricate contacts, omit failed measurements, or relabel generated degeneracies as inherited. An unavailable construction result is a concrete technical failure; a renderable candidate must still reach visual review despite diagnostic threshold exceedances.

Geometry bindings and clean appearance references serve different purposes. Use the measured clean skin field for generated surfaces while retaining original encoded images and source material bindings. Initialize neutral normals once. Never assign posed normals onto a shape-key Basis every frame: that double evaluation caused false pleating in host comparison renders.

Follow [the native export and cycle contract](NATIVE-FULL-LOOK-EXPORT.md). Assemble, export and seal the Lab's own build, then freshly import those exact bytes in the Lab's supplied Blender. Preserve source images, original hierarchy where present, unrelated controls and their neutral values. Verify every participating mesh's actual target inventory and serialized animation channels. Record renderer/runtime, repository/tests, fitted configuration and adapter patch.

Render actual close/reopen cycles for left, right and bilateral controls from front, oblique and profile views, with eye close-ups and matched source neutral views. Sample between construction and serialized animation knots. The cycle verifier evaluates the sealed GLB's actual weight channels on its reimported geometry and encodes those rendered PNGs into videos; it does not reconstruct an independent curve from a presumed controller. Preserve exact model and render hashes, view specifications and complete unmasked beauty frames.

Judge the rendered motion explicitly: neutral identity and return, smooth closure, eye coverage, skin shading, attached original lashes, plausible corner and profile silhouettes, and absence of distracting stretching, spikes, folds, dark stripes, popping or self-crossing. Use isolated ownership and shading views to diagnose defects. Numerical passes cannot excuse a visible defect, and numerical failures cannot veto an otherwise visually correct result.

If the Lab's own motion renders look correct, publish its sealed native GLB last and leave that artifact selected on the authorized canvas. Confirm that the selected artifact is the same model used for the rendered motion. Deliver the editable source, configuration/profile, patch, provenance, hashes, videos and truthful diagnostics alongside it. An external host model or an unselected file does not complete the stage.

If visible defects remain, preserve the candidate and evidence, identify affected views and motion intervals, and stop without another attempt. Exactly one fresh native pass is authorized after diagnosis. No other canvas or project is changed.
